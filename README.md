Rock, Paper, Scissors in Python

A simple and fun terminal game written in Python where you can challenge the CPU to a classic game of Rock, Paper, Scissors. First player to score 3 points wins!

-How It Works
1. The game prompts you to start the match.
2. Enter your move each round
3. The computer picks its move randomly.
4. The game awards 1 point to the round winner and displays the current score.
5. The first to reach 3 points wins the game.

-How to Run

-Requirements
* Python 3.x installed on your computer.

-Quick Start
1)Clone the repository

2)Navigate into the project directory

3)Run the script:
	Python main.py
